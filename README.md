# The Robot Apology

A two-line robot confession for the make.fun bounty "The Robot Apology"
(`u-suga-the-robot-apology-dd96bb59`).

Line one owns one specific, human-scale mistake — watering a fern with
cold coffee after mistaking a mug for a watering can. Line two names the
lesson that follows from exactly that mistake and the changed behaviour:
check what a container holds before pouring, by sniffing, labelling, and
asking first.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (two lines, 207 characters,
no trailing newline).
